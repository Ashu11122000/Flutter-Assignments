# Flutter & Dart Master Assignments 

This repository contains a comprehensive collection of Flutter and Dart projects designed to master everything from basic UI and state management to asynchronous data fetching, game logic, and pure Dart fundamentals.

- [ ] **Counter App:** Practice button interactions and basic state management.
- [ ] **Calculator App:** Perform arithmetic operations with type-safe inputs.
- [ ] **Random Password Generator:** User-defined criteria and string manipulation.

### Data & APIs (Flutter)
- [ ] **Todo List:** Full CRUD operations to manage tasks and projects.
- [ ] **Weather Search App:** Asynchronous API fetching and data validation.
- [ ] **Contact Management System:** Search and filter features for stored data.

### Games & Timers (Flutter)
- [ ] **Quiz Application:** Score tracking, timers, and structured question data.
- [ ] **Pixel Art Maker:** Using arrays to manage a grid and handle user click events.
- [ ] **Tic Tac Toe:** Managing game states and win conditions.
- [ ] **Pomodoro Timer:** Start, pause, and reset countdown functionalities.

### Pure Logic & Dart Fundamentals (Dart Console)
- [ ] **Type Practice:** Replicating utility types and mastering Mixins, Generics, and Typedefs.
- [ ] **Algorithmic Challenges:** Reversing strings, finding maximum numbers, and prime-checking.
